# Интерактивная карта проекта

Сайт: https://omeruno.github.io/switch-recompiler/

Pages настроен владельцем на Source: **GitHub Actions**. Для ручной публикации:
Actions → Roadmap Pages → Run workflow (рабочая ветка).
Автономный вариант: скачать `index.html` через Raw / Download raw file в GitHub
и открыть его в браузере.

Три вида: A–I целиком, ускорение и ближайшая очередь. Карточки соединены
линиями; внутри — сделанное, оставшиеся задачи, ограничения, критерий завершения
и исходные документы. Поиск работает по всем карточкам, фильтр — по состоянию.
Ссылку на выбранную карточку можно скопировать. На телефоне карта вертикальная.

`index.html` также можно скачать и открыть автономно: стили, данные и код
встроены в один файл, внешних зависимостей нет. Документы и CI требуют сети.

## Обновление вместе с дорожной картой

Источник состояния — `PROJECT_STATUS_RU.md`, `ACTIVE_ROADMAP.md` и subsystem docs.
В `index.html` редактируется JSON в блоке `roadmap-data`: дата, проверенный SHA
кода и его CI, текущий рубеж, карточки, координаты и связи трёх представлений.
`runtimeSha` относится к проверенному коду, а не к коммиту оформления сайта.
Это зафиксированный обзор, а не живая телеметрия GitHub.

Различайте готовую ограниченную базу, изолированный прототип, работающий путь
приложений и аппаратную приёмку. Не вычисляйте общий процент из числа карточек.
При смене рубежа обновляйте также заголовок и блок «Мы здесь» над картой.

Проверка данных и существования документов:

```sh
python3 tools/check_roadmap_site.py
python3 -m http.server 8765 --directory docs/roadmap
```

Откройте http://localhost:8765/ и проверьте вкладки, поиск, фильтры,
карточку/ссылку, клавиатуру, масштабирование и мобильную ширину.

`.github/workflows/roadmap-pages.yml` публикует только содержимое этой папки
в GitHub Pages из рабочей ветки `claude/wonderful-hawking-10mpr0`.
Основной CI сохраняет шесть проверок runtime; в host job добавлена проверка карты.
