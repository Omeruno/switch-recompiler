# FreakOut для Switch — прототип перевода демоверсии на ARM64

Проверки используют оригинальные инструкции из публичной Windows-демоверсии. Они привязаны к SHA-256 `69830e276dceeb1017be49a6193c6cfaa0905c6397b8aa9c2907e8707f4adce9`. Путь к EXE передаётся при запуске. [Демоверсия JoWooD](https://www.gamepressure.com/download/freak-out-extreme-freeride-demo/z33880).

## Результаты

- **Автоматический перевод функции.** PCRecomp сгенерировал C для функции по RVA `0x2660D0`. Zig собрал его в ARM64 ELF. Для 10 036 входов совпали результат и флаги CF, PF, ZF и SF. Обе архитектуры проверялись в Unicorn.
- **Первые инструкции запуска.** Переведён код от точки входа PE, включая пролог, который устанавливает запись обработки исключений. Хост вернул базу образа на `GetModuleHandleA(NULL)`, а игра прочитала заголовок PE и дошла до `__set_app_type(2)`. У ARM64 и x86 совпали аргументы обоих вызовов, адреса возврата, стек, EBP и цепочка SEH. `__set_app_type` в тесте отмечает границу запуска.
- **Прогон всего EXE.** Общий конвейер PCRecomp создал 26 файлов C и таблицу с 25 660 записями. В это число входят дополнительные точки входа для диспетчера. Первый файл C прошёл проверку синтаксиса GCC после явного подключения сгенерированного заголовка. Полная компиляция и корректность всех точек входа ещё не проверены. Образ игры, рантайм Win32 и графику ещё предстоит связать. Нативной сборки `.nro` пока нет.

## Как воспроизвести

Нужны Python, Zig 0.15.2 и [PCRecomp](https://github.com/sp00nznet/pcrecomp). Проверялось с веткой main на ревизии `7c07a0b42059b6dc4313d9b4ebded6f7a72db8f3`. В скачанном установщике игровой EXE находится в `setup1.cab` под именем `TARGETDIRFreakOut.exe`.

```sh
python -m pip install -r requirements.txt
python check.py /path/to/FreakOut.exe /path/to/pcrecomp /path/to/zig
```

Скрипт генерирует два ARM64 ELF и промежуточный C в `build/`. В архиве только тесты и инструкции. Память гостя в тестах отделена от адресов ARM64 и моделируется одним буфером. При переносе всей игры потребуется поддержка областей памяти, файлов, потоков и импортов.

Следующая проверка — загрузить секции PE в гостевую память, реализовать используемые CRT-импорты и пройти инициализацию до входа в код игры. Далее подключаются окно, D3D9, ввод и звук.
