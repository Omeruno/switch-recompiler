# FreakOut Extreme Freeride — проверка Single Race

Команды ниже запускают оригинальный x86-код Windows-демо в диагностике на Linux. Скрипт подаёт клавиатурный ввод, которым игра сама выбирает Single Race, Go Ski, Broken Back Mountain и Frozen Creek. Для рендера проверяемого кадра используется OpenGL с Mesa.

## Запуск

Укажи распакованную копию демоверсии. Понадобятся `FreakOut.exe`, системные DLL рядом с ним, оригинальный `Data2.bnd`, `filemap.txt` и каталог `Data` с шейдерами и звуковыми банками из установщика. Для Frozen Creek в том числе нужны банки `Data/Common/Sound/3D/LEVEL3D.fsb`, `Data/Common/Sound/Ambient/AMB.fsb` и `Data/Common/Sound/Logic/LOGIC.fsb`.

```sh
python -m pip install -r requirements-3d.txt
python scene_demo.py /path/to/demo/FreakOut.exe /path/to/demo frozen-creek \
  --single-race
python render_scene.py frozen-creek/scene/scene.json frozen-creek.png
```

Для нового запуска выбери пустой выходной каталог. На 594-м вызове Present отображается начало пролёта над трассой Frozen Creek. Для кадра выбора события используй `--present 470`. Ключ `--descent` подаёт ввод для пропуска пролёта и подтверждения обучения и берёт кадр спуска #1220. На заезд выделяется 512 МиБ адресного пространства гостя. Укажи один и тот же каталог `--save-dir` в разных запусках, чтобы оригинальная игра повторно открывала свой профиль.

## Проверка ввода

В запущенной игре Esc открыл паузу. Enter в меню паузы вернул сцену. Во время пролёта с вертолётом Enter вызвал HUD и окно Tutorial. Повторное нажатие Enter на Accept закрыло обучение и начался спуск.

Проверка стрелки влево использовала две ветви из одного состояния оригинальной игры после Accept. На одинаковом номере кадра различались положение камеры и положение лыж и палок на экране. Проверка проводилась в Linux-диагностике.

## Графика и загрузка

- Добавлены CRT-операции, которыми демо читает описание трассы и передаёт скрипт в Lua.
- Скрипт Frozen Creek читается из оригинального архива `Data2.bnd`, если в установленной копии его нет отдельным файлом.
- Добавлено преобразование полных mip-уровней через D3DX. Демо использует его при загрузке поверхностей и преобразовании BGRA в DXT5 с цветовым ключом.
- Прочитаны банки звука трассы, персонажей и музыки из оригинального архива установщика. Для доступа к путям Windows добавлен поиск без учёта регистра.
- Рендерер на ПК исполняет проходы с выводом в отдельную текстуру и использует результат на основном кадре. Поддержаны два текстурных этапа фиксированного конвейера, экранные вершины и вызовы DrawPrimitive.
- В кадре #594 156 оригинальных команд рисования и 48 текстур. На основном изображении видны снежный склон, камни, трасса и подсказка управления. В кадре #770 видны вертолёт и экипировка. Кадр #1120 уже показывает спуск, горы вокруг трассы, лыжи, палки, следы в снегу и HUD.
- Демо деформирует модель лыжника на CPU, затем выбирает GPU-шейдер, который ожидает матрицы костей. Для этой ветки рендер получает уже деформированные вершины и исходные матрицы модели и камеры. На кадре спуска #1220 отображаются лыжник, его экипировка и тень.
- Следы и контакт лыж со склоном видны в кадрах симуляции оригинальной игры. Отдельная модель деформации снежного покрова пока не подтверждена.
- Эти кадры воспроизведены на Linux. Формат FOS3 v1 для Switch пока ограничен одним буфером отрисовки.

## Сохранение и контроллер

Демо создало `Data/User/profile.pro` размером 31 238 байт. Повторный запуск открыл профиль и дошёл до меню. При ошибке записи предыдущая версия профиля остаётся доступной. Для проверки сохранения результата нужен завершённый заезд и повторный вход в профиль.

В тестовом Switch NRO нажми минус, чтобы открыть проверку контроллера. На ней видны кнопки и оси в раскладке Xbox и сканкоды DirectInput, которыми пользуется демо. Левый стик и крестовина дают стрелки. A даёт Enter, B и плюс дают Escape. Минус возвращает в меню проверки. Этому экрану файлы демо не нужны. Запуск игровых миссий и дисковое сохранение на Switch требуют запуска оригинального игрового кода на консоли.

```sh
python -m unittest discover -s tests -p '*_test.py'
```
