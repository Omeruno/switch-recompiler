# FreakOut — анализ Windows-демо и проверка перевода в ARM64

## Что проверено на демоверсии

[Демо JoWooD на Gamepressure](https://www.gamepressure.com/download/freak-out-extreme-freeride-demo/z33880) разобрано как архив. Игровой EXE и DLL извлечены из `setup1.cab` без запуска установщика. Демоверсия содержит Broken Back Mountain по описанию дистрибутива.

| Параметр | Значение |
|---|---|
| Игровой EXE | PE32 x86, 3 325 952 байта |
| SHA-256 | `69830e276dceeb1017be49a6193c6cfaa0905c6397b8aa9c2907e8707f4adce9` |
| База образа и RVA точки входа | `0x400000` и `0x1AF59E` |
| Таблица релокаций | 57 492 записей HIGHLOW и 372 записи заполнения |
| D3DX9 | 17 импортов из `d3dx9_30.dll`, включая компиляцию шейдеров, операции с матрицами и загрузку текстур |
| Direct3D и ввод | В EXE есть строки `d3d9.dll`, `Direct3DCreate9`, `dinput8.dll` и `DirectInput8Create`. Порядок динамической загрузки и вызовы интерфейсов пока не сняты |
| Звук | 58 импортов из `fmod.dll`, включая FSOUND и FMUSIC |
| C/C++ | В комплекте `msvcr71.dll` и `msvcp71.dll` |

Полные импорты четырёх извлечённых модулей находятся в `demo-pe.json`. Таблица релокаций помогает определить места, где код и данные ссылаются на абсолютные адреса. Перенос условных переходов, вызовов через указатели и Windows API проверяется отдельно.

## Проверка перевода x86 → ARM64

Рабочие зависимости устанавливаются командой `python -m pip install -r requirements.txt`.

- `python lift_check.py` переводит две синтетические функции с разными условиями ветвления. По 10 036 проверок на функцию.
- `python demo_leaf.py "путь/к/FreakOut.exe"` проверяет ручной перевод функции из демо по RVA `0x2660D0`. Она вычисляет разность двух полей структуры со знаковым сдвигом. Все 10 036 результатов совпали между оригиналом, ARM64-переводом и независимой формулой. Обе версии выполнены изолированно в Unicorn. Скрипт привязан к хешу демо.
- `python probe.py "путь/к/игре"` создаёт `freakout-pe.json` для сравнения Steam-сборки с демо. Для этой команды достаточно стандартного Python.

Комплект содержит отчёт и инструменты. Проверки выполнялись без запуска игры и без замеров на Switch.
