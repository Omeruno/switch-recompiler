# switch-recompiler

> **Статус: проект завершён (v1.0).** Код заморожен в рабочем состоянии:
> Сапёр полностью работает на Switch, Paint работает частично. Почему
> проект закрыт и что делать дальше, описано в
> [`docs/POSTMORTEM.md`](docs/POSTMORTEM.md).

Интерпретатор x86 (32-bit) с HLE-слоем Win32/MFC, который запускает
приложения Windows XP (`.exe`) на Nintendo Switch (homebrew, libnx).
Без внешних библиотек эмуляции: PE-загрузчик, декодер x86, интерпретатор,
GDI, оконный менеджер, очередь сообщений и заглушки MFC написаны с нуля.

## Итоговый статус

| Приложение | Состояние |
|---|---|
| `winmine.exe` (Сапёр) | **Полностью работает на железе**: геймплей, звук, диалоги, меню, реестр (рекорды) |
| `paint.exe` (MFC) | Окно, меню, тулбар, палитра, рисование пальцем и стиком. Работают Карандаш, Кисть, Ластик, Прямоугольник, Эллипс, Пипетка. Линия, Текст, Лупа падают; Заливка, Распылитель, Кривая, Многоугольник, Скруглённый прямоугольник и выделения ничего не рисуют |

Объём: около 14,7 тыс. строк C++, 138 реализованных функций Win32/MFC/CRT
(USER32 63, GDI32 32, KERNEL32 28, MFC42u 35 + ручные обработчики, msvcrt 19
и др.), 5 регрессионных хост-тестов.

## Структура

```
source/
  main.cpp            точка входа Switch: ввод, кадр, UI-оверлей (меню, тулбар, палитра)
  loader/             PE-парсер и разбор ресурсов
  decoder/            декодер инструкций x86
  cpu/                состояние CPU, гостевая память, интерпретатор
  win32/              HLE Win32/MFC: host_functions, GDI, окна, сообщения,
                      реестр, IAT-патчер, таблицы ABI (mfc42u_abi_table.h,
                      win32_api_abi_table.h)
tests/                хост-тесты (регрессия Сапёра) и харнесс trace_paint
tests/data/           машинный код для тестов (test*.bin)
tools/                run_host_tests.sh, генерация таблицы ABI MFC42u, аудит заглушек
docs/                 архитектура, итоги, архив журнала
romfs/                сюда кладутся .exe (в репозиторий не входят)
```

## Сборка для Switch

Нужен devkitPro (devkitA64 + libnx).

1. Положить `winmine.exe` и `paint.exe` из своей копии Windows XP в `romfs/`.
   Сами программы в репозиторий не включены: это файлы Microsoft.
2. `make`
3. Скопировать `switch-recompiler.nro` на карту в `/switch/`.

CI (`.github/workflows/ci.yml`) собирает `.nro` в образе
`devkitpro/devkita64` и выкладывает его артефактом (без `.exe` внутри,
их всё равно нужно положить в `romfs/` и пересобрать).

## Хост-тесты (Linux/WSL, g++)

```bash
sh tools/run_host_tests.sh                      # 5 регрессионных тестов Сапёра
sh tools/run_host_tests.sh path/to/paint.exe    # плюс прогон Paint, дамп экрана в paint_output.ppm
```

Те же тесты гоняет CI на каждый push.

## Методология

Каждый баг подтверждается дизассемблированием или трассировкой на реальном
прогоне, без догадок. После фикса: компиляция, 5 тестов Сапёра, затем Paint.
